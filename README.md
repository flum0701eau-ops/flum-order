# FLÜM ORDER SYSTEM

FLÜM（フリューム）のシーシャカフェ＆バー用の
QRオーダーシステムです。

---

## 🚀 システム概要

このサイトは、各テーブルごとにQRコードを設置し、
注文を自動でAirレジに振り分けるためのシステムです。

---

## 🪑 テーブル判別機能

URLパラメータでテーブルを識別します。

例：
- `?t=1` → 卓1
- `?t=2` → 卓2
- `?t=3` → 卓3
- `?t=4` → 卓4
- `?t=5` → 半個室

---

- テーブル別オーダー振り分け

- Instagramリンク
